# Security and private data

This is an experimental application-drafting tool. Full portal coverage and
unattended operation are not established. Read [privacy](PRIVACY.md) for the
plain-text profile, host service and university draft-data boundaries.

Do not post real academic records, profiles, screenshots, credentials, government
identifiers, session tokens or unredacted logs in public issues.

For a vulnerability, use **Security → Report a vulnerability** when private
reporting is available. Otherwise open a minimal issue asking for a private
reporting channel, without exploit details or personal data. Never upload
someone else's data to demonstrate a defect.

Fixes target the current development preview. Older previews have no separate
maintenance or security-support guarantee.
