# Schema provenance

`plugin.schema.json` is the unmodified Agent Plugins 1.0.0 schema retrieved on
2026-10-13 from https://agent-plugins.org/schemas/1.0.0/plugin.schema.json, linked
by OpenAI's official packaging guide. It is a development validation resource,
not an applicant/runtime file and is excluded from the plugin ZIP.

ZIP checks also follow https://developers.openai.com/plugins/deploy/submission-errors.
The local validator uses a conservative 240-character path limit of its own;
the public error reference does not publish a numeric path-length limit.
No local check substitutes for the portal's private scans or review.
